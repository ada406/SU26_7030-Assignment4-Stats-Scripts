This assignment follows the SciPy tutorial at this link: https://scipy-lectures.org/packages/statistics/index.html

The manual folder contains a Jupyter notebook that works through the tutorial. 
There is one cell for each example section. 
There is one cell for each exercise. 
There are comments expllaining purpose of each step. 
There are markdowns to break the tutorial into different topics. 


Files and descriptions: 
`stats_python.ipynb`: Main notebook
 `environment.yml`: Conda environment specification
 `brain_size.csv`: Brain size / IQ dataset
 `iris.csv`: Iris dataset
 `wages.txt`: wage dataset (from StatLib linked in tutorial)
 `../.gitignore`: Repo ignore rules (includes `.ipynb_checkpoints/`
